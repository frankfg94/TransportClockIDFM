## Delivered

- The `/map` route is backed by `src/features/line-map/GlobalTransportPlan.vue`.
- The static offline pack is generated by `../idfm-node-backend` and is loaded as a global bootstrap/catalog/chunk set; the WebView does not parse NeTEx and does not request one asset per line.
- Canvas2D remains the reference/fallback renderer. A bounded 1-2 Worker pool is used for large chunk decoding and large detailed culling candidates; small work stays on the main thread when structured-clone overhead wins.
- Camera, station anchors, LOD, DPR and renderer parity tests are present. V1 `DetailedLineMapPicker.vue` was not replaced or rewritten.
- The renderer has a bounded device-pixel path cache for active gestures. Station and entrance positions are still calculated from the canonical camera transform on every frame.
- The optional Carto light raster layer sits behind the transport canvas, uses the same camera transform, is bounded to 48 visible/overscan tiles in regional views and 128 in line-detail views, and leaves a neutral usable background when offline or when a tile fails. It is presentation-only and never participates in transport coordinates.
- The proximity primitive uses the packed global station spatial index for candidate culling, followed by exact WGS84 distance sorting; its indexed result is covered against the brute-force reference.
- The Android replay harness is deterministic and retains page JSON, `dumpsys meminfo` and `gfxinfo framestats` artifacts.
- Bus is an explicit opt-in layer. The default “all modes” filter excludes Bus, a separate Bus control toggles it, and the compiler writes physically separate `*-core` and `*-bus` assets. The current pack contains 100 core chunks and 104 Bus-only chunks; no geometry chunk mixes Bus with another mode. Hidden Bus chunks are also evicted from the bounded cache.
- V2 line colors now go through the existing V1 `createLinePresentation` resolver. The current preload has `color`/`textColor` fields, but the compiler audit reports `line-color-palette-missing: 2011`: those values are still family fallbacks rather than a complete official per-line palette.
- The distant/global LOD now loads compact offline core/Bus assets (`regional.json`: 405,795 bytes / 742 paths; `regional-bus.json`: 4,819,825 bytes / 13,768 paths) generated from precompiled LOD1 geometry. The Bus asset is fetched only when Bus is visible. Across the pack, 8,733 paths use GTFS; the remaining 5,777 paths are explicitly marked `netex-schematic-fallback` until more audited GTFS shapes are prepared. The runtime no longer renders bootstrap endpoint-to-endpoint rays once the relevant regional asset is available.
- Pan inertia now keeps a single CSS-pixel/ms unit from pointer sampling through integration, caps sparse-event velocity, cancels stale RAFs, and re-anchors the remaining pointer after pinch so a gesture cannot catapult the camera.

- Therefore the final Android gate and the Definition of Done remain incomplete. Thresholds in `performance-gate.json` are unchanged.
